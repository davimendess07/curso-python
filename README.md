# Curso Python 3 do Zero ao Avançado

Estudos do curso [Python 3 do Zero ao Avançado](https://github.com/luizomf/cursopython2023) (Luiz Otávio Miranda), com exercícios complementares no [Beecrowd](https://www.beecrowd.com.br/).

## Estrutura

- `01-fundamentos/` — tipos de dados, variáveis, coerção de tipos, bool
- `02-operadores-strings/` — operadores aritméticos, concatenação, f-strings, precedência
- `beecrowd/` — exercícios de lógica no Beecrowd

## Método de estudo

1. Assistir a aula uma vez, digitando o código junto
2. Fechar o vídeo e reproduzir o código de memória
3. Notas mínimas (só conceitos não óbvios, sem transcrever aula)
4. Commit no GitHub desde o início
